# TurtleBot3 Burger: NO PID vs PID (วิ่งตรง 1.2 m)

สรุปผลจาก rosbag 70 run บนหุ่นจริง (ROS 2 Jazzy) เปรียบเทียบ `drive_distance` (NO PID) กับ `turtlebot3_ekf_drive` (PID + EKF)

- รายงานฉบับเต็ม: [turtlebot3_pid_vs_nopid.pdf](turtlebot3_pid_vs_nopid.pdf) (หรือดาวน์โหลด [report.html](report.html) มาเปิดในเบราว์เซอร์)
- รูปกราฟ: `f*.svg`

## ชุดข้อมูล

| กลุ่ม | ความเร็วที่สั่ง (m/s) | จำนวน run |
|---|---|---|
| NO PID | 0.0335 / 0.067 / 0.134 | 5 ต่อความเร็ว |
| PID (หลังจูน) | 0.0335 / 0.067 / 0.134 | 5 ต่อความเร็ว |
| NO PID unbalance (ถ่วง 358 g ด้านซ้าย) | 0.0335 / 0.067 / 0.134 | 5 ต่อความเร็ว |
| PID unbalance (ถ่วง 358 g ด้านซ้าย) | 0.0335 / 0.067 / 0.134 | 5 ต่อความเร็ว |
| PID (ก่อนจูน) | 0.0335 / 0.067 | 5 ต่อความเร็ว |

ชื่อโฟลเดอร์ bag: `(nopid|pid)_1.2m_<ความเร็ว>v_<ระยะที่วัดด้วยตลับเมตร cm | ครั้งที่ | unbalance_ครั้งที่>`

## ผลหลัก

**ความเร็ว (ช่วงวิ่งนิ่ง)**

| กลุ่ม | 0.0335 m/s | 0.067 m/s | 0.134 m/s |
|---|---|---|---|
| NO PID: error ความเร็วจริง | −12.6% | −11.4% | −2.9% |
| PID หลังจูน: error ความเร็วจริง | +1.4% | +1.2% | +1.1% |
| PID หลังจูน: cmd peak ตอนออกตัว / setpoint | 1.40× | 1.31× | 1.16× |
| PID ก่อนจูน: cmd peak ตอนออกตัว / setpoint | 2.25× | 2.10× | – |

- NO PID ช้ากว่าที่สั่งอย่างคงที่ทุก run เพราะ `turtlebot3_node` ส่ง `int(v*100)` ให้ OpenCR ความเร็วจึงถูกปัดลงเป็นจำนวนเต็ม cm/s (0.0335 → 3 cm/s, 0.067 → 6 cm/s)
- PID ชดเชยโดยสั่ง cmd สูงกว่า setpoint +18% / +9% / +5% ความเร็วจริงจึงเหลือ error ประมาณ +1%
- การจูนลดการพุ่งของ cmd ตอนออกตัวจากประมาณ 2.2 เท่า เหลือ 1.2–1.4 เท่า

**ทิศทาง (yaw จาก IMU)**

- หุ่นสมดุล: ทุกกลุ่มวิ่งตรง yaw เบี่ยงไม่เกิน 2.6° (37 จาก 40 run ไม่เกิน 1.5°)
- Unbalance ที่ 0.0335 และ 0.067 m/s: ยังวิ่งตรงเหมือนเดิม
- Unbalance ที่ 0.134 m/s:
  - NO PID หันขวาสะสม −10.6° (ทั้ง 5 run) ปลายทางเยื้องขวาประมาณ 12 cm
  - PID ลดเหลือเฉลี่ย −2.5° แต่ต่างกันมากในแต่ละ run (−7.2° ถึง +2.5°) และ yaw ส่าย ±2–3°
- สาเหตุคือล้อไถล encoder จึงมองไม่เห็นการหมุนนี้ มีแค่ IMU ที่วัดได้

## สร้างรายงานใหม่

ต้องมีโฟลเดอร์ bag (ไม่ได้รวมไว้ใน repo เพราะมีขนาด 1.8 GB)

```bash
source /opt/ros/jazzy/setup.bash
python3 extract.py <โฟลเดอร์ NO_PID>      # อ่าน bag แล้วสร้าง runs.pkl
python3 figs.py                            # สร้างรูป f*.svg
python3 build.py                           # สร้าง report.html
```

สคริปต์ `figs.py` และ `build.py` กำหนด path แบบ absolute ไว้ (`/home/isaac/turtlebot3/NO_PID/report/`) ถ้าย้ายเครื่องต้องแก้ path ก่อนรัน
